# ecommerce-certamen
Este proyecto consiste en una plataforma web e-commerce básica para la empresa ficticia "TechStore". Los objetivos son:

- Mostrar una lista de productos.
- Permitir búsquedas.
- Mostrar los detalles de cada producto.

## Tecnologías a utilizar

- HTML, CSS (Flexbox)
- JavaScript
- Node.js (para simular servidor)
- React
- Git y GitHub
